# Sistema PetDayCare

PetDayCare es un sistema para la gestión y reserva de servicios especializados para mascotas. Permite a los usuarios registrar sus mascotas con información como especie, raza, edad, tamaño y necesidades especiales, y reservar servicios como guardería, hospedaje, paseos, entrenamiento y bienestar.

El sistema gestiona la disponibilidad de espacios y personal, reservas, pagos, servicios adicionales, cuidadores, fechas recurrentes, notificaciones e incidencias. Además, los administradores pueden configurar servicios, horarios, precios, promociones, restricciones y políticas de cada centro afiliado.

PetDayCare busca ofrecer una experiencia segura, personalizada y de calidad, facilitando la gestión del cuidado de las mascotas y permitiendo incorporar nuevos servicios y centros de atención de manera flexible.
